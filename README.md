# 🤖 AI Finance Assistant

An AI-powered assistant that reads invoices, categorizes transactions, and answers finance questions.  
Built with Python, OpenAI/Gemini API, and Streamlit.

### 🛠️ Tech Stack
`Python` `Pandas` `OpenAI API` `Streamlit` `OCR` `NLP`

### ✨ Key Features
- **Invoice Reading**: Extract data from invoice images/PDFs using OCR
- **Transaction Categorization**: Auto-categorize expenses into Food, Transport, etc
- **Finance Q&A**: Ask "How much did I spend on food this month?"
- **Web App**: Simple UI with `app.py`

### 🚀 How to Run
1.  `pip install -r requirements.txt`
2.  Add your API key to `.env`
3.  `streamlit run app.py`
